تطبيق عملي لاحتراف API Versioning وأعماق Entity Framework Core المتقدمة

حالة النظام: متصل ويدعم InMemory DB 🟢

📌 الدرس الأول: API Versioning

يُستخدم لتطوير وتحديث شكل البيانات المُرجعة (Responses) دون كسر عمل التطبيقات أو العملاء (Clients) القدامى.

طريقة التنفيذ: عبر الـ URL Path (`/api/v1/` و `/api/v2/`).

الفرق: V1 يعيد البيانات الأساسية للمنتج، بينما V2 يعيد البيانات مضافاً إليها اسم الفئة (`CategoryName`).

⚙️ الدرس الثاني: Advanced EF Core

  • AsNoTracking & Select: لتقليل استهلاك الذاكرة وجلب الحقول المطلوبة فقط (Projection) عبر استعلام SQL واحد (JOIN) لتجنب مشكلة N+1 Queries.
  • Pagination: تقسيم البيانات عبر `Skip` و `Take` لأداء أسرع.
  • Indexes & Soft Delete: فهرسة حقل `Name` لتسريع البحث، واستخدام `HasQueryFilter` لإخفاء المحذوفين تلقائياً.
  • Change Tracking & Concurrency: التعديل الآمن عبر تتبع الكيانات، وحماية البيانات من الكتابة المتزامنة عبر `RowVersion` واستثناء `DbUpdateConcurrencyException`.
