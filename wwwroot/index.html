📌 إصدارات الـ API Versioning

يُستخدم لتطوير وتحديث شكل البيانات المُرجعة (Responses) دون كسر عمل العملاء القدامى.

V1: يعيد البيانات الأساسية للمنتج.

V2: يعيد البيانات مضافاً إليها اسم الفئة (`CategoryName`).

⚙️ ميزات Advanced EF Core

  • Soft Delete: حذف آمن للسجل عبر تغيير قيمة حقل `IsDeleted` إلى true.
  • Pagination & Projection: تقسيم النتائج وجلب الحقول المطلوبة عبر `Select`.
  • Concurrency Control: الحماية من التعديلات المتزامنة عبر الـ `RowVersion`.
